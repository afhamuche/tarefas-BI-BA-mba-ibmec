# Análise de Dados e Tomada de Decisões com BI e BA

Repositório com as minhas tarefas da disciplina **Análise de Dados e Tomada de Decisões com BI e BA** (IBM3705 / 15306207, turma 3001, 2026.2B).

Sou aluno do **MBA em IA, Big Data e Data Science para Negócios** no **IBMEC**, e este repositório reúne as atividades, análises e anotações que desenvolvo ao longo do curso.

## Sobre a disciplina

A disciplina trabalha o uso de dados para apoiar decisões de negócio, combinando Business Intelligence (BI) e Business Analytics (BA). Entre os temas que aparecem nas atividades:

- Métricas de produto e de negócio: North Star, árvore de métricas, AARRR, HEART, OKR e KPI
- Unit economics: CAC, LTV, ARPA, MRR e payback
- Ativação, retenção, coortes e curvas de retenção
- Análise exploratória de dados com SQL e notebooks (média, mediana, distribuições e séries temporais)
- Visualização de dados para comunicar resultados

## Ferramentas

- SQL e notebooks em Python, executados em uma plataforma de dados em nuvem
- Bases de exemplo usadas em aula, como `samples.tpch` e datasets sintéticos fornecidos pela disciplina

## Como usar

1. Clone o repositório:
   ```bash
   git clone <url-do-repositorio>
   ```
2. Abra a pasta da aula que quiser consultar.
3. Importe os notebooks na sua plataforma de dados ou leia os arquivos diretamente.

## Aviso

Este é um repositório de estudo, criado para fins acadêmicos. Os dados e os resultados refletem exercícios de sala de aula, não situações reais de negócio. O material da disciplina (slides, bases e enunciados) pertence aos seus respectivos autores e à instituição.
